# 拼汪 PAWZZLE

一个原生 JavaScript + SVG 的网页异形拼图原型。首关将一张 14 只小狗紧密嵌合的插画，沿每只小狗的身体轮廓切成 14 块；完整拼合后形成一个大狗头。

## 启动与构建

需要 Node.js 20 或以上，无第三方运行依赖，不需要安装 npm 包。

```sh
npm run dev
```

打开终端输出的 `http://127.0.0.1:5187`。端口可通过 `PORT=5174 npm run dev` 修改。

```sh
npm test
npm run build
```

构建产物在 `dist/`，可部署到普通静态网站服务的根目录。不要直接以 `file://` 打开；浏览器需要通过 HTTP 加载 ES modules。开发服务器仅监听本机，并只提供页面、运行模块与图片资源。

## 玩法

- 拖动拼片，可在桌面的空白位置自由放下。
- 相邻拼片在正确相对位置靠近时，会吸附成一组；整组仍可移动，可先在底板外拼好再放回。
- 拼片或拼片组靠近底板上的对应位置时自动归位，归位后锁定。
- 工具栏提供暂停、查看原图、计时／自由模式和音效开关。
- 「整理碎片」帮助找回散落的拼片，「帮我一块」放置一个拼片组，重新开始可重置关卡。
- 进度保存在当前浏览器中；清除网站数据会清除存档。
- 键盘操作：Tab 选择拼片，方向键移动，Shift + 方向键加速，回车吸附；空格暂停，P 查看原图。

## 实现结构

| 文件 | 职责 |
| --- | --- |
| `src/main.js` | SVG 渲染、鼠标／触控／键盘交互、计时、弹窗与本地存档 |
| `src/puzzle-engine.js` | 不依赖 DOM 的拼图模型：移动、相邻吸附、分组合并、归位、提示与存档校验 |
| `src/packing.js` | 按实际狗形边界排列散落拼片，保留间距且不旋转、不缩放 |
| `src/level.js` | 关卡入口，提供狗头轮廓、拼片路径、相邻关系及原图坐标 |
| `src/mosaic-data.js` | 沿插画中每只小狗边界描出的拼片几何数据 |
| `src/style.css` | 桌面布局、移动端布局与视觉反馈 |
| `public/assets/dog-mosaic.png` | 14 只小狗拼成狗头的完整原画 |
| `public/assets/pieces/` | 沿原画轮廓导出的 14 张透明 PNG 拼片 |
| `tests/puzzle-engine.test.js` | 核心拼图行为的 Node.js 自动化测试 |
| `tests/level.test.js` | 实际关卡轮廓、相邻图以及拼接／完成／恢复的集成测试 |
| `tests/packing.test.js` | 桌面和手机散片区域的完整容纳、间距及无重叠验证 |
| `scripts/segment-mosaic.py` | 从原图提取犬形区域、共享边界与诊断图，生成关卡几何数据 |
| `scripts/build.mjs` | 将页面、模块与素材复制成静态发布目录 |

素材流程从完整插画开始：先生成紧密嵌合的小狗群，再沿每只小狗的耳朵、背部、尾巴和爪子建立独立区域，提取边缘路径与相邻关系。每块拼片从完整原图中按真实轮廓导出透明 PNG，运行时再用同一轮廓对齐边缘，图像和形状使用同一坐标系。因此拿起一块时，拿起的是这只小狗本身；拼回时原图像素也会回到原位。

如需重新生成当前素材的切割数据，使用装有 Pillow 和 NumPy 的 Python 环境运行 `python scripts/segment-mosaic.py`。脚本会更新 `src/mosaic-data.js`，并在 `work/mosaic-diagnostics/` 输出区域标注、分割预览与独立拼片图。区域归属和深色毛发的辅助标记针对当前插画人工校准过；更换原图时需要重新检查这些标记。正常玩游戏和部署不需要 Python。

模型中的 `x`、`y` 是应用到原始路径的平移量。同组拼片共享平移量，相邻拼片平移量足够接近即可合并，因此在底板外也能拼接。放回底板后，平移量统一为底板原点。模型默认吸附阈值为 18 个画布单位，本关界面使用 20。

## 验证

`npm test` 覆盖底板外拼接、非相邻拼片不吸附、传递合并、整组移动、底板归位与锁定、提示完成、重置，以及合法存档恢复和损坏存档拒绝。关卡集成测试还检查真实路径是否闭合、路径是否位于拖动边界内、相邻关系是否双向连通、拼片是否完整覆盖大轮廓，以及整关是否能够拼合完成。布局测试用实际狗形边界验证桌面和手机散片区可容纳全部拼片，彼此保留间距。

界面回归可按以下顺序操作：先在底板外拼接两块并移动整组；再放回底板；检查暂停和原图弹窗期间计时；刷新确认位置与计时恢复；最后用「帮我一块」完成关卡。

## 当前范围

首版只有一个固定关卡；拼片无需旋转或翻面。桌面空间有限，窄屏将散片排列在底板下方并随页面滚动。存档仅保存在本机浏览器，没有账号、云同步、排行榜或多人协作。新关卡仍需准备完整插画并校准每只小狗的切割边界，尚未提供自动出题编辑器。
